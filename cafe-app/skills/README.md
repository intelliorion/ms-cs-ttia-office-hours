`cafe-design.md` is the Café design guide, written for this app: how to run a proof-of-concept design conversation (one question at a time, the Café rules, when to stop) and how to tell a clear request from an unclear one. The design questions and the tool picker send it as guidance.

`writing-plans.md` is the Superpowers "writing-plans" skill, copied verbatim (front matter removed) under the MIT licence in LICENSE-superpowers.md. The plan step sends it as guidance.

The app only sends these as guidance text inside prompts; it never executes them.
